This is a sample post. Every version of the site reads the same posts, so you only write each one once.

How to add a post

  • Add an entry to shared/app/data/blogs.php with a unique slug.
  • Write the body as HTML in shared/content/blogs/{slug}.html.
  • Put the cover image in shared/assets/imgs/.

Drafts and scheduling

Set 'status' => 'draft' to hide a post. A post with a future date stays hidden until that day, so you can write ahead.
